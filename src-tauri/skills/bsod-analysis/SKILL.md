# 蓝屏分析

## 收集证据

1. 查询最近 7 天 System 日志中的 BugCheck、Kernel-Power 和 WHEA 相关事件，记录事件 ID、时间和停止代码。
2. 列出 `C:\Windows\Minidump` 与 `C:\Windows\MEMORY.DMP` 是否存在、大小和修改时间，不读取无关内存内容。
3. 收集系统版本、最近安装的驱动或更新、CPU/内存信息。
4. 询问蓝屏发生时的操作、是否超频、是否新增硬件，区分偶发和可复现故障。

## 分析与处理

- 没有转储解析器时，明确说明证据限制，不凭停止代码武断归因。
- 如需安装调试工具，单独说明来源、大小和用途，并走下载安装审批。
- 优先建议撤销近期变更、更新或回退明确相关的驱动；不要批量删除驱动。
- 禁用服务、修改启动配置或删除转储前必须说明影响并走相应审批。
- 最终报告列出证据、最可能原因、备选原因和下一步验证方法。
