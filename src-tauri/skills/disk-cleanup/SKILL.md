# 磁盘清理

## 先测量

1. 读取各盘总容量和剩余空间。
2. 先列出用户临时目录、Windows 临时目录、回收站、Windows Update 缓存等候选位置的大小与文件数量。
3. 对大目录逐层统计，避免盲目遍历整个系统盘。不要读取与清理无关的个人文档内容。

## 再分类

将结果分为：
- 可直接重建的临时文件和缓存；
- 需要用户选择的下载、安装包和旧文件；
- 不应触碰的系统文件、应用程序数据、用户文档。

## 清理约束

- 默认只提出方案，不自动删除。
- 删除前给出准确路径、预计释放空间、是否可恢复；递归删除和磁盘级操作始终二次确认。
- 跳过正在使用或无权限的文件，不要为清理临时文件而强制结束应用。
- 不使用来源不明的清理脚本，不关闭系统保护。
- 清理后重新测量并报告实际释放空间。
