# 开机与登录缓慢排查

## 只读测量

1. 收集系统版本、开机时间、内存、系统盘类型与剩余空间。
2. 用固定只读命令读取启动应用、计划任务概况、服务状态与最近启动相关事件。
3. 检查 `Get-CimInstance Win32_StartupCommand` 等启动项来源，区分用户启动项、服务和驱动。
4. 查看最近 30 天 Application/System 日志中启动性能、磁盘和超时错误。

## 优化原则

- 先给出耗时和资源证据，不按软件名称随意禁用。
- 不禁用安全软件、触摸板、音频、同步或硬件驱动，除非用户确认不需要相关功能。
- 启动项修改必须可逆，记录原状态和恢复方法。
- 磁盘错误、内存不足和恶意软件迹象应单独提示，不要把所有问题都归结为启动项。
- 建议用户重启验证后对比结果。
