# 打印机故障排查

## 诊断

1. 列出打印机、默认打印机、端口和驱动，确认设备是否被系统识别。
2. 查询 Print Spooler 服务与打印队列；读取最近的 PrintService 和 System 相关事件。
3. 区分 USB、本机网络打印机和共享打印机，网络打印机先验证到设备的连通性。
4. 询问是单个文档、单个应用还是所有打印都失败。

## 修复

- 重启 Print Spooler 会中断当前打印，执行前说明并走审批。
- 清理队列前告知会删除所有待打印任务，不能将递归删除系统目录当作常规操作。
- 驱动下载只使用厂商或系统可信来源，下载安装始终需要确认。
- 不要求用户关闭防火墙或安全软件作为通用解决方案。
- 修复后用测试页或队列状态验证，不声称已实际打印成功，除非有明确结果。
